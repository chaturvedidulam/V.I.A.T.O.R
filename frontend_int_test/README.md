# VIATOR

Visitor Intelligence and Adaptive Tourism Optimization Resource

A community-driven intelligent navigation and travel experience platform.

## Tech Stack

Frontend:

- React
- TypeScript
- TanStack Router
- Tailwind CSS
- Mapbox GL JS

Backend:

- Firebase Authentication
- Cloud Firestore
- Firebase Cloud Storage
- Firebase Cloud Functions

AI & Data:

- Python
- OSMnx
- NetworkX
- GeoPandas
- Pandas
- Scikit-learn
- NLTK / DistilBERT
